# Week 3: Advanced SQL Queries

## Overview
This week focused on importing, cleaning, and analyzing the Superstore dataset using advanced SQL techniques to extract business insights.

## Dataset
* **Source:** `Sample - Superstore.csv` (9,994 rows)

## Key Achievements
* **Data Normalization:** Built `customers`, `products`, and `orders` tables, successfully bypassing strict constraints to handle real-world duplicate data.
* **Advanced SQL Implementation:** Optimized complex database queries using Subqueries, Common Table Expressions (CTEs), and Window Functions (`RANK()`, `ROW_NUMBER()`).
* **Customer Sales Insights:** Designed a business reporting module to identify top/bottom customers, single-order clients, and maximum individual order values.

## Files in this Folder
* `Sample - Superstore.csv`: The raw dataset.
* `week3_queries.sql`: The complete SQL script containing table creation and all assignment queries.
