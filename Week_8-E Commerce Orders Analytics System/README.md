# E-Commerce Data Analytics Pipeline

An end-to-end data engineering and analytics pipeline built with Python, Pandas, and SQLite. This project demonstrates the ability to generate, clean, test, and analyze large datasets to uncover business-critical insights.

## Project Overview
This system simulates a real-world e-commerce data environment. It handles the complete data lifecycle: generating raw transactional data, processing it through a cleaning pipeline, loading it into a relational database, and serving business intelligence through advanced SQL queries and an interactive command-line tool.

## Project Structure
```text
